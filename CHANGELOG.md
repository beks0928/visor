# Изменения

## v0.1.1

Исправление: события агентов и звук «агент закончил» больше не пропадают.

- Если файл связи с хуками агентов (`visor.sock`) пропадал, Claude Code и Codex переставали сообщать Visor о своей работе: не было звука и статус не менялся. Теперь Visor замечает это и поднимает связь заново за 15 секунд.
- Самопроверка Visor работает на отдельном сокете и не мешает запущенному приложению.

Обновление той же командой:

```bash
curl -fsSL https://raw.githubusercontent.com/beks0928/visor/main/scripts/install.sh | bash
```

## v0.1.0

Первая версия Visor.

### Установка

```bash
curl -fsSL https://raw.githubusercontent.com/beks0928/visor/main/scripts/install.sh | bash
```

Скрипт скачивает Visor, проверяет контрольную сумму, ставит в «Программы» и запускает. Можно и через `Visor.dmg`: если macOS не открывает его, нажмите правой кнопкой → «Открыть».

### Что внутри

- Агенты: Claude Code, Codex, Gemini CLI, Qwen Code. Запросы разрешения прямо в вырезе, лимиты плана.
- Плеер Spotify и Apple Music с текстом песен, лайками и плейлистами.
- Awake: Mac не засыпает при закрытой крышке, с таймером, порогом заряда и хотспотом iPhone.
- Календарь, Pomodoro, таймер, секундомер, мировые часы.
- Чат с 10 моделями по вашим ключам, буфер обмена, полка, калькулятор с курсами.

Нужна macOS 15 или новее. Нашли ошибку? [Сообщите](https://github.com/beks0928/visor/issues/new/choose) или нажмите «Сообщить о проблеме» в меню Visor.
